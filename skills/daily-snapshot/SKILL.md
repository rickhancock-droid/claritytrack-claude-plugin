---
name: daily-snapshot
description: Show what changed across connected accounts since the previous daily snapshot.
---

Use this when the user asks what changed since yesterday or wants the daily snapshot.

1. Call changes.recent.
2. Summarize the connected net worth change and the account changes the tool returned.
3. If there is no snapshot yet, say so in the tool's own words. Do not invent a change.
4. Use the numbers exactly as returned. Nothing moves money.

Write the answer in plain text. Use no emoji, coloured dots, check marks or other symbols, and no em or en dashes. Say a status in words, such as ahead, on track or behind.
